# 命名与结构

> 从 `AGENTS.md` 拆出来的细节页。新建文件、加接口、改别人模块的调用方式之前看这一页。

## 1. 目录职责（放错地方 = PR 打回）

```
app/
  main.py               # 入口（禁止修改；要加路由用 include_router）
  api/                  # 路由层：只做参数校验 + 调 pipeline，不写业务
  pipelines/
    text/               # 文本预处理、规则、Prompt
    audio/              # VAD / ASR
    vision/             # OCR / 截图解析
    decision/           # 打分、阶段判定、融合
    knowledge/          # 剧本库、案例库、检索、入库流水线
    notify/             # 监护人推送、报告生成
  core/                 # 配置、日志、异常、依赖注入
  schemas/              # ★ 契约，只有队长能改
  kb/                   # 知识库数据（剧本、案例）
tests/                  # pytest，按模块建子目录
data/                   # 测试素材（不入库，见 .gitignore）
docs/
  INDEX.md              # ★ 自动生成，禁止手改
  任务地图.md            # 谁的活先做、谁在等谁、交接与验收怎么算
  需求覆盖表.md          # ★ 自动生成：每条需求由哪张任务单负责
  需求清单.md            # 需求基线（29 FR / 11 NFR / 11 交付物）
  技术学习路线.md         # 学什么、按什么顺序学
  测试方案.md            # 用例与指标口径
  agents/               # 本文件的细节页（技术栈/命名/工作流/验收/故障）
  modules/              # 每个模块一份说明（新增文档放这里）
  decisions/            # ADR-0001.. 一条决策一个文件
  reports/              # 任务回执（每完成一个任务一份）
  tickets/              # 任务单（派活用）
  archive/              # 归档，不再维护
scripts/                # check.ps1 / docs.py / smoke.py
docker/                 # compose 与 Dockerfile
```

## 2. 命名约定

- **目录与文件**：`app/pipelines/<域>/<功能>.py`，域只限 `text / audio / vision / decision / knowledge / notify`；
  一个文件一件事（`normalize.py` 只清洗，`rules.py` 只出证据）。
- **模块对外函数**：每个模块只暴露 1–3 个**动词**函数（`extract` / `transcribe` / `evaluate` / `build_report` / `notify_guardian`）；
  `_` 开头是内部实现，跨模块不许调。
- **契约类型**：只定义在 `app/schemas/`；字段 **snake_case 全拼**（`script_id`，不写 `sid`）；字段名与类型**冻结**。
- **枚举值**：小写字符串，或 `"L0".."L3"` 这类短码；**不许中文枚举值**。
- **接口路径**：业务接口 `/api/v1/<资源>`（复数、全小写）；健康检查 `/health`；演示页 `/demo`。
- **错误**：统一 `{"error": {"code": "...", "message": "..."}}`，`code` 用**小写下划线**（`bad_request` / `internal_error`）；
  前端与脚本按 `code` 分支，不匹配文案。
- **测试**：文件 `tests/test_<模块>_<行为>.py`，函数 `test_<行为>_<期望>`（例：`test_scoring_empty_evidence_returns_l0`）。
- **分支 / 提交 / 文档 / 任务单 / 人物代号**：见工作流页与任务地图页，此处不重复。

## 3. 你能改什么

- 任务单里写明的路径；
- 你负责模块目录下的 `tests/`；
- 你负责的 `docs/modules/<模块>.md` 与 `docs/reports/` 里你自己的回执。

**一律不许碰**（碰了就是越界）：

```
app/schemas/**      ← 契约，只有队长改
app/main.py
app/core/**
docker/**
scripts/**
Makefile
docs/INDEX.md       ← 自动生成，手改必冲突
docs/需求覆盖表.md   ← 自动生成，跑 docs.py matrix 重建
AGENTS.md  OWNERS.md  .github/**
```

要改契约或入口：在任务单评论里写「申请：改 X 的 Y，理由 Z」，等队长改完并在群里公告，`git pull` 后再继续。
