# 技术栈与架构决策

> 从 `AGENTS.md` 拆出来的细节页。先看结论，别通读；要改已定的事，先读对应 ADR。

## 1. 技术栈与版本

依据 `pyproject.toml` + `requirements.txt`。**只有队长能改这张表**。

| 层 | 选型 | 版本 | 硬性约束 |
|---|---|---|---|
| 语言 | Python | ≥3.10（本机 3.12，CI 3.11） | 禁 `StrEnum`、`datetime.UTC`、`typing.Self`（要用 `typing_extensions`） |
| Web | FastAPI + uvicorn | fastapi≥0.110，uvicorn[standard]≥0.27 | 加路由只能 `include_router`，不改 `app/main.py` |
| 校验 | Pydantic **v2** | ≥2.5 | 用 `model_dump()` / `field_validator`；禁 `.dict()`、`@validator`、`class Config` |
| HTTP | httpx | ≥0.27 | 只用于测试与调外部 API |
| 测试 | pytest | ≥8.0 | 插件（asyncio 等）同样走申请制 |
| 检查 | ruff | ≥0.6（本机 0.17.3） | 配置写死在 `pyproject.toml`：line-length 110、target py310、`select E,F,I,UP,B`、`ignore E501,B008` |
| 存储 | SQLite（标准库 `sqlite3`）+ JSON | — | 不引 ORM、不引数据库服务 |
| 检索 | 纯 Python | — | 不引 jieba / faiss / numpy / scikit-learn |
| 模型 | 外部 HTTP API（LLM / ASR / OCR） | — | 不进 `requirements.txt`；**没配就返回“未启用”，不许编结果** |
| 前端 | 单文件 HTML + 原生 JS | — | 无构建、无 CDN（内网演示也要能跑） |

**要加依赖**：开 Issue（模板 `01-requirement`，标题以“依赖申请”开头），写清「包名 / 用途 / 不装的替代方案」；
队长批准后由队长改 `requirements.txt`。不许自己 `pip install` 完就提交。

## 2. 已定的架构决策（只放结论，细节读 ADR）

| ADR | 一句话结论 | 什么情况下才推翻 |
|---|---|---|
| [ADR-0001](../decisions/ADR-0001-fastapi.md) | 用 FastAPI 起 HTTP 服务，不用 Flask / Django / 单脚本 CLI | 需要前端同构、或长期长连接时 |
| [ADR-0002](../decisions/ADR-0002-evidence-contract.md) | 模块之间**只**传 `app/schemas` 里的 `Evidence / Decision / Alert / Report`，不传裸 dict | 出现跨模块高频二进制流（如原始音频）时 |
| [ADR-0003](../decisions/ADR-0003-check-commands.md) | 验收只认四条命令（lint / test / smoke / 文档门禁），不认人工评审 | CI 超过 5 分钟，或 smoke 慢到没人愿意跑 |
| [ADR-0004](../decisions/ADR-0004-module-boundary.md) | 现在**不做**模块边界重构，只记录触发条件（“改 A 断 B”出现两次） | 症状出现后做“包入口 + 架构测试”，约 40 行 |
| [ADR-0005](../decisions/ADR-0005-前端未定时怎么看效果.md) | 前端未定时验收看“命令 + 真实输出”，页面只算加分；四条命令是底线不是证据 | T-04 定稿且稳定两周后，可降级为贴截图，但要留可复现命令 |

## 3. 新增或推翻一条决策

1. 新建 `docs/decisions/ADR-000N-<短名>.md`，照 ADR 现有格式写：背景 / 决策 / 代价 / 推翻条件；
2. 在本页 §2 表格加一行（一句话结论 + 推翻条件）；
3. 群里发一句「决策变更：xxx」，让所有人 `git pull`。

**ADR 只追加，不改写。** 旧决策被推翻时，新 ADR 里写明“取代 ADR-000X”，不要回去改原文。
