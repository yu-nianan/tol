# 故障排查

> 命令跑不通时先看这一页。所有条目都是本机真实踩过的，不是假设。

## 1. `gh` 说“未安装”，但确实装了

**现象**：`where gh` / `Get-Command gh` 都找不到；`gh pr ...` 报 command not found。

**原因**：`gh` 装在 `C:\Users\Lenovo\.local\gh\bin\`，这条目在**用户 PATH** 里；
但 DSH 会话与终端进程的 PATH 是启动那一刻的快照，新装的目录不会自己进来。

**处置**：写绝对路径，不要修 PATH。

```powershell
$gh = 'C:\Users\Lenovo\.local\gh\bin\gh.exe'
& $gh --version            # 应输出 2.x
& $gh auth status          # 应显示登录 yu-nianan
```

## 2. 报“没装 ruff / pytest”，其实装了

**原因**：机器上有多个 Python，`scripts/check.ps1` 挑到的那个没装包。

**处置**：显式指定解释器，别去改 PATH。

```powershell
pwsh scripts/check.ps1 -Task all -Python "C:\Python311\python.exe"
```

要确认某个解释器有没有装齐：

```powershell
python -c "import fastapi, ruff, pytest, pydantic; print('ok')"
```

## 3. 网页打不开 / 返回 503 / 返回 404

| 现象 | 原因 | 处置 |
|---|---|---|
| 连不上（connection refused） | 服务根本没起 | 用 `scripts/start.ps1` 起（它会自动挑解释器、检测端口占用） |
| 503 + `demo not configured` | 前端/演示页依赖的后端未配置 | 看 `.env` 或环境变量是否缺；这是**设计如此**，不是 bug |
| 404 | 路径不对：业务接口都带 `/api/v1` 前缀 | `/api/v1/detect`，不是 `/detect`；健康检查是 `/health`，演示页是 `/demo` |
| 检测结果为空/全 0 | 模型没配（LLM/ASR/OCR 走外部 API） | 返回“未启用”是正确行为；演示要用规则链路或先配好 key |

## 4. 切错分支：PR 里混进别人的改动

**真实事故**：在 `feature/decision-runtime-storage`（别人的分支）上提交了本应在 `main` 基线之上的改动，
PR 里出现 22 个文件、看起来像“我改了所有东西”。

**根因**：切分支前没确认当前位置。

**处置**（下次避免，而不是事后收拾）：

```powershell
git fetch origin
git branch --show-current          # 我在哪？
git status --short                 # 工作区干净吗？
git switch -c <新分支> origin/main  # 从干净基线开新分支
```

已经错了：从 `origin/main` 拉新分支 → `git cherry-pick <只属于你的那个提交>` → 关掉旧 PR 并留一句原因。

## 5. 端口被占用

`start.ps1` 会检测并提示换端口。手动方式：

```powershell
$env:PORT = 8001
pwsh scripts/start.ps1
```

## 6. smoke 失败，但单元测试全绿

`smoke.py` 需要一个**正在运行的服务**。它连不上时会提示“先启动 uvicorn”。

```powershell
pwsh scripts/start.ps1 -NoBrowser      # 另开一个终端常驻
python scripts/smoke.py                # 再跑冒烟
```
