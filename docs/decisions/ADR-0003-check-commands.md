# ADR-0003 · 代码审查降级为"三条命令"

- **状态**：已采纳（2026-11-02）
- **决定**：不做人工代码评审，改为 `lint / test / smoke` 三条命令 + PR 贴输出。
- **理由**：队员看不懂代码，人工评审会退化成"队长读全部代码"，八周内不可执行。
- **影响**：所有人；PR 没贴输出不合并。
- **复核**：若出现"命令全绿但演示跑不通"，需要补一条端到端用例。

## 这个决定的真实代价（重要）

它放弃了"代码质量"这个维度，只保"能不能跑"。所以：

- 队长必须**偶尔抽查**核心链路的可读性，否则两个月后会收到一坨没人敢改的代码。
- 三条命令本身可能被"骗"（硬编码返回值、注释掉真实调用），所以 AGENTS.md 里第 5 节第 3 条是硬禁令，
  并且冒烟用例要跑真实链路，不能只测结构。
