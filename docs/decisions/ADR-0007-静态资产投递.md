# ADR-0007 · 前端资产由 /static 投递，不再内联成单文件

- **状态**：生效（2026-11-25）
- **一句话**：`GET /static/{path}` 按白名单后缀输出 `frontend/` 下的真实文件；`index.html` 只做壳，不再内联 JS/CSS。

## 背景

接入原型前端前，`frontend/index.html` 是 1616 行的单文件：`app.js`（29KB）和 `style.css`（11KB）被**内联复制**了一份。原注释写着原因——"`web.py` 的 `GET /` 只返回 index.html，没有静态文件路由，所以内联了同一份代码"。

这带来四个具体问题：

1. **两份真相**：`frontend/app.js` 与 `index.html` 里的副本会漂移，改完忘内联就静默不生效；
2. **diff 不可读**：任何一个前端改动都表现为 1600 行文件里的一小段，评审看不出改了什么；
3. **没法测**：无法断言"页面引用的是外部资产"还是"又内联回去了"；
4. **原型搬不进来**：原型是 4 个 js + 1 个 css 的多文件结构（`file://` 直接跑），塞进单文件等于重写。

约束：`app/main.py` 是禁区（禁止修改），所以不能用 `app.mount(...)` 在入口挂 `StaticFiles`；`app/api/` 属于队长可写区域，可以在路由层加一个只读端点。

## 决定

1. `app/api/web.py` 新增 `GET /static/{path:path}`：`FileResponse` 输出 `frontend/<path>`，只允许 `.js .css .html .svg .png .ico .webmanifest` 七种后缀。
2. 路径穿越用 `root not in target.parents` 判断（`Path.resolve()` 之后），**不以字符串前缀判断**；`.` 开头的隐藏文件一律拒绝。
3. `page_path()` 与静态路由共用同一个 `FRONTEND` 常量，避免"页面找得到、静态找不到"。
4. 保留 `PAGE` 兜底页（`frontend/index.html` 缺失时返回），并新增回归测试：兜底页必须不含 `/static/app.js`，防止有人把内联版本又塞回去。
5. `index.html` 只留结构与 7 个 `<script src>`（顺序 `presets → api → profile → store → alert → report → app`），样式走 `/static/style.css`。

## 代价

- 多一个端点与一份后缀白名单要维护（白名单外的资源要改代码，这是有意的）；
- 没有缓存头与压缩，每次刷新都重新取（演示与内网够用）；
- 静态文件路径解析依赖 `parents[2]` 定位仓库根——打包成 wheel 部署时会失效，届时要改配置项。

## 什么情况才推翻

如果要做缓存 / gzip / 指纹版本号，正解是用 `app.mount("/static", StaticFiles(...))`，但那需要改 `app/main.py`（队长禁区）：**走契约变更流程**，由队长改入口并在此 ADR 追加一条；不要为了省事在路由层手写缓存。
