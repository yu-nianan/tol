# <模块名>

> 用法：复制到 `docs/modules/<模块>.md` → 改文件名 → `owner` 填代号（队长 / A / B / C / D）→
> 删掉本段提示 → 提交前跑 `python scripts/docs.py index` 和 `python scripts/docs.py check`。
> 全文控制在 120 行以内；超过说明这块该拆了。

## 一句话职责

只写一句：**吃 X，吐 Y**。超出这句的都算越界。

## 输入 / 输出

只写 `app/schemas/` 里已经存在的名字，不要在这里自造字段（要加字段走契约变更）。

| 方向 | 类型 | 从哪里来 / 到哪里去 |
| --- | --- | --- |
| 入 | `Evidence` | 由上游 `pipelines/xxx` 产出 |
| 出 | `Decision` | 交给 `decision/engine` 汇总 |

## 关键实现与取舍

2–5 条，每条一句话，写清"为什么这么做、因此放弃了什么"。不要贴大段代码。

- 例：规则先行、模型兜底——理由是模型超时会拖垮演示，代价是规则覆盖不全。

## 边界：不做什么

列 3 条"看起来该我做、其实不该我做"的事。这一段是防止下一个 Agent 越界改别人模块的。

## 怎么测

- 单测位置：`tests/<模块>/`
- 一行可复制的命令：`python -m pytest tests/<模块> -q`

## 常见坑

踩过的坑写在这里，一条一行。没踩过就别编。

## 改动须知

改这个模块会影响谁、要不要动 `app/schemas/`、谁审批。默认：动契约 = 找队长。
