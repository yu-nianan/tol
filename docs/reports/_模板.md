# 任务回执：<一句话说清做完了什么>

> 用法：复制本文件 → 改名为 `YYYY-MM-DD-<模块>-<你的名字>.md` → 四节填满 → 提交。
> **`owner` 填代号（队长/A/B/C/D），从任务单 §7 抄**；填真名、工具名或空着，CI 都会红。
> 四节缺任何一节，`python scripts/docs.py check` 会红。

## 做了什么

（一两句话，说结果不说过程。例：文本判别接入了 12 类话术规则，剧本命中能进 Evidence。）

## 没做完 / 已知问题

（没做完的写"没做"，不要留空。已知问题写清触发条件，例：方言语音转写未验证。）

## 下次接手要知道什么

（这一段最重要——写给下一个 Agent：文件在哪、哪个函数是入口、哪条路是死的、
哪个参数是拍脑袋定的。）

## 怎么验收

```
命令：pwsh scripts/check.ps1 -Task all
输出：<贴完整输出，不要只贴最后一行>
命令：python scripts/docs.py check
输出：<贴完整输出>
```

## 改动清单

- `app/xxx.py`（改了什么）
- `tests/test_xxx.py`（补了什么用例）
- `docs/modules/xxx.md`（补了什么说明）
