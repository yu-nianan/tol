# 任务单：骨架 v0.1（已完成，留档用）

## 1. 背景

这是"从零到能演示"的第一张单，已经做完并合进 `main`（提交 `chunk: v0.1 骨架`）。
它不是为了再派活，而是为了让需求覆盖表能回答一个问题：**哪些需求已经在跑的代码里真的有了。**

## 2. 它交付了什么（可验收的）

- `app/schemas/`：`Evidence` / `Decision` / `Alert` / `Report` 四个契约，模块之间只认这四个。
- `app/pipelines/text/`：NFKC 归一化 + 脱敏 + 12 类话术规则（FR-1.1 的文本接入、FR-1.4 的同构证据）。
- `app/pipelines/knowledge/store.py`：剧本匹配 + 纯标准库 BM25 案例召回（FR-4.1 的入库与检索，`add_case()`）。
- `app/pipelines/decision/`：加权打分 + 阈值 + 告警 + 报告骨架。
- `app/api/web.py`：自带演示页（三个入口按钮 + 证据列表 + 报告），无构建、无 CDN。
- `tests/`：23 条单测；`scripts/check.ps1` 三条命令。

## 3. 验收命令

```powershell
pwsh scripts/check.ps1 -Task all
```

预期：lint / test 全过，smoke 5 项通过（诈骗样例 L3、正常样例 L0、端到端 <1s）。
