# 任务单：打分器 v2（薄单，开工前补齐 §3 与验收用例）

> 薄单：先在覆盖表里占住 FR-2.2 / 2.4a / 2.7，开工前 1 天把输入输出样例与用例表补满。

## 1. 背景

- 对应需求：`FR-2.2`（阶段判定 + 转账前预警）、`FR-2.4a`（融合打分）、`FR-2.7`（无证据封顶）。
- 现状：`scoring.py` 只有"剧本命中 → 分数"，没有阶段序号；`Decision` 里 `stage_index` 还是固定值。
- 一句话：让系统说得出"他现在走到第 3 阶段（隔离），再下一步就要转账"，而不是只说"像诈骗"。

## 2. 目标

1. `Decision.stage_index` 输出 1–4，并随会话轮次单调不减（除非换会话）。
2. 阶段 3（隔离）起就给出 L2；**不等转账意图出现**（这是创新轴 A 的证据）。
3. 缺维度不参与归一化（已有）→ 补：`s_cross` 缺失时按"其余维度加权"算，不记 0。
4. 无检索案例引用时 `score` 封顶 60（FR-2.7）。
