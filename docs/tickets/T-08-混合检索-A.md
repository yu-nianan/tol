# 任务单：混合检索（薄单）

## 1. 背景

- 对应需求：`FR-2.3`（检索案例并引用）、`FR-2.8`（解释要有证据）。
- 现状：`store.py` 只有手写 BM25，靠字符串切词，同义改写（"安全账户" vs "资金审查"）召回为 0。
- 一句话：把召回从"字面相同"提到"意思相近"，且**不许装任何包**。

## 2. 目标

1. `search_cases()` 返回 `(case, score, source)`，`source ∈ {bm25, ngram, fused}`。
2. 融合用 RRF（`1/(k+rank)`，k=60），两路各取 top8 再融合 top3。
3. 向量替身：字符 2-gram 的 TF-IDF + 余弦；同义词表放 `app/kb/synonyms.json`（"安全账户/资金审查/清查"同组）。
4. 引用进 `Decision.cited_case_ids`，解释里能带上案例标题。

## 3. 允许修改的路径

```
app/pipelines/knowledge/**
app/kb/cases.json, app/kb/synonyms.json
tests/knowledge/**
docs/modules/knowledge.md
```

## 4. 不许做的事

- 不许 `pip install`（faiss / sentence-transformers / jieba 都不行）；
- 不许改 BM25 的对外签名（`search_cases(text, top_k)` 保持不变）。

## 5. 验收命令

```powershell
pwsh scripts/check.ps1 -Task all
python scripts/docs.py check
```
