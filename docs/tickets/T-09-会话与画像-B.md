# 任务单：会话与画像（薄单）

## 1. 背景

- 对应需求：`FR-1.5`（多轮上下文）、`FR-2.6`（个性化阈值）。
- 现状：`engine.py` 里会话态是进程内 dict，重启即丢；角色只影响 `ROLE_BIAS` 一个常数。
- 一句话：让"第 5 轮还记得第 2 轮说过什么"，并且"换个角色，结论真的会变"。

## 2. 目标

1. `sqlite3`（标准库）落盘：`sessions` / `messages` / `alerts` 三张表，重启不丢。
2. 会话摘要：最近 5 轮压成 ≤200 字，作为 `Evidence(kind="context")` 进打分。
3. 角色画像：`role`（老人/儿童/学生/财会/普通）× 历史告警次数 → 阈值偏移，写进 `Decision.explain`。
4. 冷却：同会话 30 分钟内同等级告警只推一次；白名单命中直接 L0 并记录原因。

## 3. 允许修改的路径

```
app/pipelines/memory/**
app/pipelines/decision/engine.py      # 只加"读会话态"的调用，不改打分公式
tests/memory/**
```

## 4. 验收命令

```powershell
pwsh scripts/check.ps1 -Task all
python scripts/docs.py check
```
