# 任务单：监护人与报告（薄单）

## 1. 背景

- 对应需求：`FR-3.3`（分级推送 + 确认回写）、`FR-3.4`（报告导出）、`FR-3.5`（周期摘要）、`FR-3.6`（分角色建议）、`NFR-6`（脱敏）。
- 现状：`notify/guardian.py` 没有 webhook 就返回 `skipped`（如实），报告只有骨架文本。
- 一句话：让"紧急告警"真的能到家长手机上，并且能回写"我已介入"。

## 2. 目标

1. 三档 × 三渠道映射：L1 站内、L2 站内 + 语音、L3 站内 + 语音 + 监护人（企业微信/钉钉机器人）。
2. `POST /api/v1/alerts/{id}/ack` 回写状态（已介入/误报/已忽略），并把结论写回会话。
3. 报告五段（风险说明/证据链/剧本匹配/建议/通知记录）+ 导出 HTML（可打印成 PDF）。
4. 周期摘要：按周聚合，`C` 级需求，有入口即可。
5. 脱敏：手机号/卡号/身份证在报告与日志里一律打码（NFR-6）。

## 3. 允许修改的路径

```
app/pipelines/notify/**
app/api/alerts.py
tests/notify/**
docs/modules/notify.md
```

## 4. 不许做的事

- 不许把 webhook 地址写进代码或提交到仓库（走环境变量，`.env.example` 只放占位）；
- 不许在没配 webhook 时假装"已发送"。

## 5. 验收命令

```powershell
pwsh scripts/check.ps1 -Task all
python scripts/docs.py check
```

## 6. 验收用例（开工前补齐）

| 用例 | 输入 | 期望 | 需求 |
| --- | --- | --- | --- |
| L3 推送 | 诈骗样例 + 配置了 webhook | 群里收到消息，含等级/摘要/证据数 | FR-3.3 |
| 回写 | 点"已介入" | Alert 状态变 acked，会话里能查到 | FR-3.3 |
| 报告 | 任一告警 | 导出 HTML 五段齐全 | FR-3.4 |
| 脱敏 | 含 138****0000 的输入 | 报告与日志里不出现完整号码 | NFR-6 |

## 7. 交接

- 前端（T-04）只读 `Alert` 契约，不直接调 notify；
- 演示视频的第 4 幕就用这条：告警 → 家长手机响 → 点"已介入"。
