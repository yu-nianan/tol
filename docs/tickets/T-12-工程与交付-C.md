# 任务单：工程与交付（薄单）

## 1. 背景

- 对应需求：`FR-5.1`（一键起）、`FR-5.3`（评估报告）、`FR-5.4`（使用指南）、`FR-5.5`（演示视频）与 `NFR-1/2/3/7/9/10`。
- 现状：`docker/` 有 compose 雏形但没验证；没有压测、没有 24h 记录、没有成片。
- 一句话：评委只会用一次，那一次必须是"`docker compose up` 之后就能点"。

## 2. 目标

1. `docker compose up` 一条命令起服务，换台机器可复现（NFR-9），镜像不带素材与大模型。
2. 压测脚本：10 并发 × 10 分钟，成功率 ≥99%，P95 < 10s（NFR-1/2）。
3. 24h 守护：每小时打点，输出内存曲线与异常计数（NFR-3）。
4. 评估报告：F1 / 准确率 / 时延 / 压测四类数据 + 图表（FR-5.3）。
5. 使用指南：安装、配置、三步操作（FR-5.4）；演示视频 5 分钟成片（FR-5.5）。
6. 安全与合规：接口 token、上传大小与类型限制、密钥走环境变量（NFR-7）；界面免责声明（NFR-10）。
