# 任务单：接入原型前端（三屏）

## 1. 背景（为什么做这件事）

对应需求：`FR-3.1`（分级预警）、`FR-3.2`（语音提醒）、`FR-3.7`（角色设置）、`FR-3.3/3.4`（监护人与报告）、`FR-2.8`（可解释）的**界面侧**；这几条的验收主责仍在 T-04 / T-11，本单只做"把界面换成人能看懂的样子"。

T-04 交付的页面是能跑的最小演示页（1616 行内联单文件），当时的目标是"链路通"。之后队长另做了一版原型（`_preview/`，4 个 js + 1 个 css），把"判了什么、为什么判、判错了怎么反馈"做成了三屏，但原型里的判定是**前端假数据**。

**一句话：这次不是加功能，是把原型的界面接到真接口上，并且不留假判定。**

## 2. 目标（做完之后，什么会不一样）

1. 打开 `/` 看到的是三屏（检测 / 告警 / 报告），数据全部来自 `/api/v1/*`，页面上没有一条写死的分数或证据。
2. 检测页能把"对方说的"和"我说的"分开录，左右分栏显示证据与维度贡献，失败时给出能看懂的原因（连不上后端 / 400 / 413 / 500）。
3. 告警页能看到同会话的告警升级史、该条告警的证据链、监护人手机预览与"我已介入"回写。
4. 报告页能出一份五段齐全、可打印成 PDF 的报告，含逐轮分数曲线。
5. 前端资产拆成多文件，`index.html` 小于 20KB，且有测试守着"不许再内联回去"。

## 3. 输入 / 输出样例（写死，不要"大概"）

| 你拿什么试 | 期望看到 |
|---|---|
| 打开 `http://127.0.0.1:8765/` | 三屏可切换，概览里 KB 剧本数与案例数来自 `/health` |
| 预设 S01 逐轮粘 6 轮（对方 / 我交替） | 分数逐轮上升，阶段条从"接触"走到"诱导转账"，L3 时弹全屏并语音播报 |
| 只粘"对方"的话、不粘"我"的话 | 能出分，但受害状态一栏提示"只录了对方，受害信号缺失" |
| 后端停掉再点发送 | 红字提示"连不上后端"，**不出现任何假分数** |
| 触发 L2 以上后打开告警页 | 列表有该会话的告警（越严重越靠上），点开有证据链与三段状态 |
| 点"结束对话 · 生成报告" | 报告页五段齐全 + 逐轮曲线 + 维度条，可打印 |
| 刷新 `#/report/<session_id>` | 不发 404，直接回到报告页 |

**不要改**：`app/main.py`（禁区）、`app/kb/**`、打分权重与阈值、其他任务的 pipeline。

## 5. 不许做的事（本次特有）

- **不许把原型里的 `analyze()` 假判定搬过来**：所有分数、等级、证据必须来自 `POST /api/v1/detect/text`。
- **不许引入 npm / CDN / 构建步骤**：原生 JS + 相对路径，`file://` 打不开没关系，但 `http://` 必须零依赖。
- **不许前端自己算维度贡献**：没有 `dims` 就显示"后端未提供维度"，不许本地加权。
- **不许把手改的分数写进 `sessionStorage` 当真相**：缓存只用于"刷新不丢列表"，不参与判定。
- **不许让报告随对话实时变化**：报告是"结束对话"那一刻的快照。

### 已知限制（降级项，必须随 PR 写清楚）

| 项 | 现状 | 原因 |
|---|---|---|
| 告警列表 | 前端 `sessionStorage` 累积，刷新不丢、换设备丢 | 后端没有列表接口（只有按 id 取） |
| 逐轮曲线 | 前端累积每轮 `(turn, score, level)` 自绘 | `report` 不含逐轮历史 |
| 证据的"第几轮 / 谁说的" | 用 `ev.text` 与轮次文本互相包含匹配 | `Evidence` 没有 `turn/speaker` 字段（契约未定） |
| 告警"已读"态 | 只做两态：已推送 / 已介入 | `Alert` 没有 `read_at` 字段 |
| 画像卡 | 纯前端推断，只影响建议文案，**不影响分数** | 后端 `build_profile` 的偏移只在服务端生效且不回传 |

## 8. 交付时会问的三个问题（提前想好）

1. **维度有分，但证据里没看到对应条目，怎么解释？** —— 同一维度可由多条弱证据累积（如 3 条各 0.3 的"催促"话术），`evidence` 只列前若干条原始条目；`dims` 是聚合值，口径在 `scoring.py`。
2. **没有告警列表接口，刷新页面列表为什么还在？** —— `sessionStorage` 缓存 + 首次进入时按会话重建；换浏览器就没了，这是降级项。
3. **原型里的假判定去哪了？** —— 全部删除，`analyze()` 不再存在；页面所有数字都来自一次真实 `detect` 响应，连不上后端就报错，不给分数。
