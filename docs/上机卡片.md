# 队友上机卡片

> 目标：**30 分钟内**在自己电脑上把项目跑起来，并且能跑出一次绿。
> 卡住超过 15 分钟不要自己硬试——把报错原文截图发群里。

## 第 1 步：装 Python（3.11 或 3.12）

- Windows：去 python.org 下 3.12，安装时**勾上 "Add python.exe to PATH"**
- 装完验证（PowerShell 里）：

```powershell
python --version
```

- 显示 `Python 3.12.x` 就对了。显示 3.13.x 也先试；如果后面装库报错，再降到 3.12。

## 第 2 步：拿到代码

```powershell
cd D:\项目      # 你自己的文件夹，别放在中文路径太长的地方
git clone git@github.com:yu-nianan/tol.git
cd tol
```

没配 SSH 的话会报 `Permission denied (publickey)`——**这就是要开 Issue 的事**，
别自己瞎折腾，按 Issue 模板 `02-blocked` 提，队长给你配。

## 第 3 步：装依赖

```powershell
python -m pip install -r requirements.txt -i https://pypi.tuna.tsinghua.edu.cn/simple
```

（加清华镜像是因为默认源在国内很慢。装 5 分钟没动静就 Ctrl+C 重来。）

## 第 4 步：跑起来看页面

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/start.ps1 -Open
```

浏览器自动打开 `http://127.0.0.1:8000/`，看到输入框和三个按钮 = 成功。
关掉窗口服务就停了；再跑一次上面的命令即可。

## 第 5 步：四条命令（判断"我做完没做完"）

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1 -Task lint
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1 -Task test
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/check.ps1 -Task smoke
python scripts/docs.py check
```

四条全绿 → 你才有资格说"我做完了"。**任何一条红，把整段输出贴进 PR 描述**（不要只贴最后一行）。

## 你每天只会做这四件事

1. 拉最新代码：`git pull`
2. 开一个分支：`git checkout -b feature/<模块>-<你现在做的事>`
3. 改代码 + 跑四条命令
4. 提交推送：`git add .` → `git commit -m "feat: 做了什么"` → `git push -u origin feature/...`
   然后去网页上点 **Compare & pull request**，把四条命令的输出粘进去。

## 六条别踩的坑

| 坑 | 现象 | 怎么办 |
|---|---|---|
| 直推 main | 被拒 `protected branch hook declined` | 永远走分支 + PR，没有例外 |
| 装了个新库 | PR 被打回"不许新增依赖" | 先在任务单里申请，等队长批 |
| 跑了别的 Python | 报 `No module named fastapi` | 用 `scripts/check.ps1 -Python <你的解释器路径>` 指定 |
| 改了 `app/schemas/` | PR 被打回"契约只有队长改" | 提 Issue，队长改完你 `git pull` |
| 手改 `docs/INDEX.md` | CI 红 | 跑 `python scripts/docs.py index`，别手改 |
| 说"我优化了结构" | 没人知道你做完了没 | 只报四条命令的结果 |

## 交作业的两句话格式

做完任何一件事，在群里发这两行（不要写小作文）：

```
做了什么：T-02 音频切成 3 段，能返回段数和时长
结果：四条命令全绿（lint/test/smoke/docs）
```

## 遇到问题按这个顺序找

1. 这张卡片有没有写（先看一遍）
2. `docs/INDEX.md` 里找对应文档（一次只看 1–3 份，别全读）
3. 任务单里"卡住找谁"
4. 都不是 → 开 Issue（模板 `02-blocked`），把**报错原文**和**你试过的两件事**写进去
