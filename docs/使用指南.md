# 使用指南：安装、配置、三步操作

> 对应需求 `FR-5.4`（使用指南：安装、配置、操作步骤）。目标：一个没参与开发的人，照本文能在 10 分钟内把服务跑起来并完成一次演示。
> 更细的项目背景见 [项目背景](项目背景.md)；5 分钟演示分镜见 [演示脚本](演示脚本.md)。

## 1. 你需要什么

| 项 | 要求 | 说明 |
|---|---|---|
| 操作系统 | Windows 10 / 11、Linux、macOS | 本文命令以 Windows PowerShell 为例 |
| Python | 3.10 及以上 | 仓库在 3.12 上开发，3.10 / 3.11 也可 |
| 浏览器 | Chrome / Edge 新版 | 演示页无构建、无 CDN、无外部字体 |
| 网络 | 演示时不需要外网 | 页面与接口同源；外部模型未配置时按降级路径运行 |
| 端口 | 8123（可改） | 本文统一用 8123，避免和本机其他服务冲突 |

## 2. 安装

在仓库根目录（能看到 `app/`、`frontend/`、`docs/` 的那一层）执行：

```powershell
# 1) 建虚拟环境
python -m venv .venv

# 2) 允许当前窗口执行激活脚本（只影响当前窗口）
Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass

# 3) 激活
.\.venv\Scripts\Activate.ps1

# 4) 安装运行依赖
python -m pip install -r requirements.txt
```

如果不想激活虚拟环境，把后面的 `python` 换成 `.\.venv\Scripts\python.exe` 即可。
仓库没有前端构建步骤，**不需要 `npm install`**。

## 3. 启动与自检

```powershell
python -m uvicorn app.main:app --host 127.0.0.1 --port 8123
```

另开一个终端自检：

```powershell
Invoke-WebRequest http://127.0.0.1:8123/health -UseBasicParsing | Select-Object -ExpandProperty Content
```

期望看到 `"status": "ok"`，且 `kb_scripts` 大于 0（知识库剧本已加载）。浏览器打开：

```text
http://127.0.0.1:8123/
```

页面标题是「多模态反诈智能助手」，地址栏会自动补上 `#/detect`，说明拿到的是三屏页面而不是内置兜底页。

> 端口被占用就换一个，例如 `--port 8124`。前端全部用同源相对路径（`/api/v1/...`），换端口不需要改代码。

## 4. 配置（全部走环境变量）

配置定义在 `app/core/config.py`（`Settings`）。所有项都有默认值，**不配置也能跑**：

| 变量 | 默认 | 作用 | 不配置会怎样 |
|---|---|---|---|
| `APP_NAME` | `反诈智能助手` | FastAPI 应用名 | 用默认值 |
| `APP_VERSION` | `0.1.0` | 版本号 | 用默认值 |
| `LOG_LEVEL` | `INFO` | 日志级别 | 用默认值 |
| `LLM_BASE_URL` | 空 | OpenAI 兼容接口地址 | 不调用模型，只用规则证据 |
| `LLM_API_KEY` | 空 | 接口密钥 | 同上；`LLM_BASE_URL` 与 `LLM_API_KEY` 都配了才启用 |
| `LLM_MODEL` | 空 | 模型名 | 同上 |
| `GUARDIAN_WEBHOOK` | 空 | L3 告警推送给监护人（企业微信 / 钉钉机器人等） | 只写日志，报告里如实记 `skipped` |

PowerShell 临时设置示例（只影响当前窗口）：

```powershell
$env:GUARDIAN_WEBHOOK = "https://example.invalid/webhook"
python -m uvicorn app.main:app --host 127.0.0.1 --port 8123
```

**红线**：没配就返回「未启用 / skipped」，系统不会伪造模型结果，也不会假装通知已发出。

## 5. 三步操作

### 第一步：检测

1. 打开 `http://127.0.0.1:8123/#/detect`。
2. 选择角色：普通用户 / 老年人 / 儿童 / 学生 / 财务人员。角色会改变阈值（见 `app/schemas/alert.py` 的 `ROLE_BIAS`：老人 +8、儿童 +10、学生 +5、财务 −3）。
3. 粘贴可疑内容，或点三个预设之一：「正常消息」「冒充公检法」「客服退款」。
4. 点「检测」。

预期结果：

| 输入 | 预期等级 | 页面行为 |
|---|---|---|
| 正常消息 | L0（灰） | 留在检测页，显示「仅记录、不生成告警」；不会编造告警 |
| 冒充公检法（普通角色） | L3（红） | 自动跳到告警页 |
| 冒充公检法（学生 / 财务） | 随角色偏移 | 分数变化；财务人员阈值更高，可能只到 L2 |
| 客服退款 | L1–L2 | 自动跳到告警页 |

> 同一句话换个角色分数会变，这是需求 `FR-3.7`（角色设置）与 `FR-3.3`（监护人联动）里的角色偏移，不是 bug。

### 第二步：告警

告警页展示：

- 等级色条：L0 灰 `#6b7280`、L1 蓝 `#1e70c0`、L2 橙 `#ef6c00`、L3 红 `#c62828`；
- 风险分、命中剧本与阶段（如「冒充公检法 · 诱导转账」）；
- 证据条目：名称 + 原文 + 权重 / 置信度 / 来源；
- 判定理由。

可执行动作：

| 按钮 | 调用 | 结果 |
|---|---|---|
| 我已介入 | `POST /api/v1/alerts/{id}/ack`，`{"action": "ack"}` | 状态 `open` → `acked`，报告「通报记录」里多一条家长确认 |
| 误报，忽略 | 同一接口，`{"action": "dismiss"}` | 状态 `open` → `dismissed` |
| 生成报告 | 跳到 `#/report/{session_id}` | 见第三步 |

> 直接刷新告警页也能打开：hash 路由不会把 `#/...` 发给后端。但告警存在服务进程内存里，**重启服务后旧告警会 404**，重新检测一次即可。

### 第三步：报告

报告页五段，数据来自 `GET /api/v1/report/{session_id}`：

1. **风险概述**：分数、等级、是否需人工、是否封顶、模态、条数 / 轮数；
2. **证据链**：按权重排序的证据（名称 + 原文 + 置信度）；
3. **剧本匹配**：剧本、阶段、阶段权重、命中信号；未命中时如实写「未命中」；
4. **处置建议**：按等级 / 剧本给的可执行动作；
5. **通报记录**：`in_app` / `voice` / `guardian` 各通道的真实状态，以及家长 ack 记录。

点「打印 / 导出 PDF」→ 浏览器打印对话框 → 目标选「另存为 PDF」。

## 6. URL 与接口一览

| 页面 | URL | 依赖接口 |
|---|---|---|
| 检测 | `/#/detect` | `POST /api/v1/detect/text` |
| 告警 | `/#/alert/<alert_id>` | `GET /api/v1/alerts/<alert_id>`、`POST /api/v1/alerts/<alert_id>/ack` |
| 报告 | `/#/report/<session_id>` | `GET /api/v1/report/<session_id>` |

健康检查：`GET /health`。其他可用接口：`GET /api/v1/stats`、`GET /api/v1/scripts`、`GET /api/v1/cases`。

## 7. 常见问题

**Q1：打开 `/` 是旧的蓝色兜底页，不是三屏页？**
`app/api/web.py` 只在 `frontend/index.html` 存在时优先返回它。确认在仓库根目录启动服务，且该文件存在。

**Q2：端口被占用？**
换端口：`python -m uvicorn app.main:app --port 8124`。页面与接口同源，不需要改前端。

**Q3：检测返回 422？**
文本为空或全空白会被拒（`DetectTextRequest` 校验）；粘贴后再点，单次最多 4000 字。

**Q4：告警页 404（`alert_not_found`）？**
告警存在进程内存，重启服务就没了。回检测页重新检测。

**Q5：报告页 404（`session_not_found`）？**
该会话还没检测过。先在检测页跑一次，或从告警页点「生成报告」。

**Q6：报告里「通报记录」显示 skipped？**
没有配置 `GUARDIAN_WEBHOOK`。这是**真实状态**，不是故障：系统写日志并如实记录，演示时请照实讲，不要说「已经发给家长了」。配置后再演示真实推送。

**Q7：改了 `frontend/app.js` / `style.css`，页面没变化？**
当前后端 `GET /` 只返回 `frontend/index.html`，没有静态文件路由。`index.html` 内联了同一份样式与脚本；改完源文件后需要重新内联（命令见回执 `docs/reports/2026-11-07-frontend-D.md` 的「下次接手要知道什么」）。如果后续在 `app/main.py` 挂载了 `StaticFiles`，可改为外链。

**Q8：手机 420px 下有横向滚动？**
页面按 420px 设计（无固定宽度、长文本自动换行）。若出现横向滚动，记下浏览器与机型提 issue，不要用 `overflow-x: hidden` 掩盖。

**Q9：能离线演示吗？**
可以。页面无 CDN、无外部字体；后端依赖本地知识库。只有配置了外部 LLM / ASR / OCR 时才会访问外网。

## 8. 数据与隐私

- 三个预设文本改写自 `data/samples/*.txt`，不含真实号码与姓名。
- 文档、截图、演示视频里不出现真实手机号 / 身份证；示例统一写 `138****0000`。
- 报告里的证据原文来自输入文本，演示时不要粘贴真实聊天记录。
