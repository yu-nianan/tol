# 演示脚本：5 分钟分镜

> 配套文档：[使用指南](使用指南.md) ｜ [项目背景](项目背景.md)
> 总时长 5:00。目标顺序：**正常消息 → 冒充公检法 → 告警 → 家长手机收到 → 点「我已介入」→ 报告导出**。

## 0. 演示前 10 分钟检查

| 检查项 | 命令 / 动作 | 通过标准 |
|---|---|---|
| 服务 | `python -m uvicorn app.main:app --host 127.0.0.1 --port 8123` | 日志出现 `Uvicorn running on http://127.0.0.1:8123` |
| 健康 | 打开 `http://127.0.0.1:8123/health` | `status` 为 `ok`，`kb_scripts` > 0 |
| 页面 | 打开 `http://127.0.0.1:8123/` | 标题「多模态反诈智能助手」，三屏页面，不是旧兜底页 |
| 家长通道 | 配置 `GUARDIAN_WEBHOOK` 并重启服务 | 群里能收到一条测试消息；**没配就按第 5 节降级方案讲** |
| 浏览器 | 缩放 100%，F11 全屏；另备一个手机热点 | 地址栏完整可见，420px 布局正常 |
| 数据 | 只用页面三个预设，或 `data/samples/*.txt` 里的脱敏文本 | 不出现真实号码 / 姓名 / 聊天记录 |

> 端口冲突就换 8124，并同步改浏览器地址；页面与接口同源，不需要改前端。

## 1. 时间轴总览

| 时间 | 幕 | 页面 | 一句话 |
|---|---|---|---|
| 0:00–0:30 | 开场 | `#/detect` | 四层链路 + 三屏，10 秒讲完 |
| 0:30–1:20 | ① 正常消息 | `#/detect` | L0 只记录、不告警，先证明「不误报」 |
| 1:20–2:20 | ② 冒充公检法 | `#/detect` | 老人角色 + 诈骗预设 → 命中剧本 |
| 2:20–3:10 | ③ 告警 | `#/alert/<id>` | L3 红条、证据链、阶段判定 |
| 3:10–3:50 | ④ 家长收到 | 手机 / 群消息 | 真实推送或如实讲降级 |
| 3:50–4:30 | ⑤ 已介入 | `#/alert/<id>` → `#/report/<sid>` | ack 回写，通报记录出现家长确认 |
| 4:30–5:00 | ⑥ 报告导出 | `#/report/<sid>` | 五段报告 → 打印 / 另存为 PDF |

## 2. 逐幕脚本

### 0:00–0:30 开场

- 画面：`http://127.0.0.1:8123/#/detect`。
- 台词：「这是多模态反诈智能助手。左边是检测，中间是分级告警，最后是给家长和学校看的报告。整条链路本地可跑，不依赖外网。」
- 动作：鼠标扫过顶部三步指示「检测 → 分级告警 → 监护人确认 → 安全报告」，不要逐字念。

### 0:30–1:20 ① 正常消息：先证明不误报

- 动作：
  1. 角色保持「普通用户」；
  2. 点预设「正常消息」；
  3. 点「检测」。
- 画面：停留在检测页，出现提示「本次判定为 L0 仅记录：未达到告警门槛，系统只记录、不生成告警（不会编造告警）」。
- 台词：「正常聊天不会被硬判成诈骗，L0 只记录。这里特意没有生成告警——系统不会为了演示效果编一条假告警。」
- 要点：这一屏是**诚实性**证明，不要快速跳过。

### 1:20–2:20 ② 冒充公检法：角色改变阈值

- 动作：
  1. 角色下拉选「老年人」（阈值更低，更早触发）；
  2. 点预设「冒充公检法」（文本改写自 `data/samples/scam_authority.txt`，已脱敏）；
  3. 点「检测」。
- 画面：自动跳到告警页 `#/alert/<alert_id>`。
- 台词：「同一句话，老人和普通用户的阈值不一样——这是需求里的角色偏移，老人 +8 分、儿童 +10 分，目的不是歧视，是让高风险人群更早被提醒。」
- 可选对比（时间够）：返回检测页把角色换成「财务人员」（−3 分）再检测，说明分数会变，但剧本与证据不变。

### 2:20–3:10 ③ 告警页：等级、证据、剧本阶段

- 画面从上往下指三处：
  1. **顶部色条**：L3 红 `#c62828`（L0 灰、L1 蓝、L2 橙）；
  2. **风险分与剧本**：「冒充公检法 · 诱导转账」，对应剧本四阶段里的「诱导转账」；
  3. **证据链**：每条是「名称 + 原文 + 权重 / 置信度 / 来源」，例如「冒用公检法身份」「要求保密与隔离」「诱导转账或索要验证码」。
- 台词：「分数不是模型随口给的，是规则与模型证据加权；拿不到证据时分数会被封顶在 60，防止空口判 L3。」
- 注意：页面上的证据原文是输入文本的片段，演示文本已脱敏。

### 3:10–3:50 ④ 家长手机收到

- 前提：已配置 `GUARDIAN_WEBHOOK`。
- 动作：拿起手机，展示群里收到的 L3 告警消息（标题含等级、剧本、评分、证据条数）。
- 台词：「L3 会同时走站内记录、语音外呼（未接入时如实 skipped）和监护人 webhook。现在家长手机上收到的是同一条告警。」
- **未配置 webhook 时（降级，必须照实讲）**：
  - 打开报告页的「通报记录」，指出 `guardian · skipped`、`sent: false`；
  - 台词：「当前环境没配 webhook，所以这里如实显示未推送、不会假装已发送。配一个群机器人地址就能真实推送。」
  - 不要用事先伪造的聊天截图冒充实推。

### 3:50–4:30 ⑤ 点「我已介入」：确认回写

- 动作：在告警页点「我已介入」。
- 画面：
  - 状态从「待处理」变成「已介入」，按钮变灰并显示「已介入 ✓」；
  - 点「生成报告」进入 `#/report/<session_id>`。
- 台词：「家长点一下，状态就回写到后端；报告最后一节会留下这条确认记录，而不是只有一个冷冰冰的分数。」

### 4:30–5:00 ⑥ 报告导出：五段收口

- 画面：报告页五段——风险概述 / 证据链 / 剧本匹配 / 处置建议 / 通报记录。
- 动作：点「打印 / 导出 PDF」→ 目标选「另存为 PDF」→ 保存。
- 台词：「同一份报告可以给家长、学校或社区。最后一节是真实通报状态：哪个通道成功、哪个 skipped 一目了然。」
- 收尾：读页面底部免责声明「本报告由原型系统自动生成，仅用于演练与教学，不构成法律意见」。

## 3. 每幕的验收点（自己排练时对一遍）

- [ ] 正常消息：**没有**跳告警页，出现 L0 诚实提示；
- [ ] 冒充公检法 + 老人：跳告警页，等级 L3，色条为红；
- [ ] 告警页至少 3 条证据，每条都有 label、原文、置信度；
- [ ] 家长通道：真实推送或如实 skipped，二者都不能含糊；
- [ ] ack 后按钮禁用、状态变「已介入」，报告通报记录出现 ack；
- [ ] 报告五段齐全，能导出 PDF；
- [ ] 全程没有真实手机号 / 身份证 / 姓名出现在屏幕或文档里。

## 4. 设备与录屏建议

- 主画面：1920×1080，浏览器全屏，缩放 100%；
- 备一个 420px 宽的窗口或手机，展示窄屏不横向滚动（可选，30 秒）；
- 录屏分辨率不低于 1080p；导出 PDF 后立刻打开一次，确认不是空白；
- 演示用浏览器开无痕窗口，避免旧 hash / 缓存干扰。

## 5. 兜底方案

| 故障 | 现场处理 | 话术 |
|---|---|---|
| 8123 被占用 | 换 `--port 8124`，改地址 | 「换个端口，页面同源，不用改代码。」 |
| 服务重启后旧告警 404 | 回检测页重新检测一次 | 「告警存在进程内存，重启就清空，这是原型取舍。」 |
| 报告 404（`session_not_found`） | 先检测再进报告 | 「这个会话还没跑过检测。」 |
| webhook 未配 / 群机器人失效 | 按第 3:10 节降级方案，展示 `skipped` | 「如实显示未推送，不假装已发送。」 |
| 现场断网 | 仍可演示规则链路；外部 LLM / ASR / OCR 显示未启用 | 「外部模型是可插拔的，没配就只用规则证据。」 |
| 页面白屏 | F12 看 Console；确认 `frontend/index.html` 存在、服务从仓库根目录启动 | 「先看健康检查和首页标题。」 |

## 6. 演示后清理

1. `Ctrl+C` 停掉 uvicorn；
2. 关闭无痕窗口；
3. 如果改过 `GUARDIAN_WEBHOOK`，恢复原值；
4. 检查桌面 / 下载目录：演示 PDF 可以留，**不要**把真实聊天记录或真实号码带进仓库；
5. 需要复现时，按 [使用指南](使用指南.md) 从第 2 节重来。
