# 项目背景（5 分钟版）

> 给**队友的 Agent** 读。读完你应该知道：这是个什么项目、现在做到哪一步、你的活在哪、哪些事绝对不能干。
> 更细的条款在 `AGENTS.md`，需求细节在 `需求清单.md`。**不要一次全读**，按需翻。

---

## 1. 一句话

做一个**多模态反诈助手**：用户把可疑的**短信/聊天截图/通话录音**丢进来，系统判断是不是诈骗、是第几阶段、有多严重，然后弹窗提醒、必要时通知监护人，并生成一份报告。

面向的人群是**老人和学生**（最容易被"冒充公检法""刷单返利""杀猪盘"骗的两类人）。

---

## 2. 这东西从哪来

服务外包创新创业大赛 A 类赛题 **A30**（命题企业：浙江工业大学）。题面把要求写得很死，这些数字是**评分依据**，不是形容词：

| 题面要求 | 我们的理解 |
|---|---|
| ≥10 类诈骗剧本 | `app/kb/scripts.json` 里每类一个剧本，每个剧本 4 个阶段 |
| 20 条测评集（黑白 1:1） | 要能算出准确率，所以必须自己标注；只有 20 条时置信区间很宽，我们会扩到 100 条 |
| 融合识别准确率 > 90% | 跑评测脚本出数，不是"感觉挺准" |
| 正常样本误报 < 5% | 要专门准备"含敏感词的正常对话"来测 |
| 文本/图片响应 < 10s | 端到端计时，从点击到出结果 |
| 5 项提交物 | 概要、PPT、详细方案、演示视频、企业补充材料（测评集+评估报告+可运行程序） |

**注意**：比赛评分里"技术难度"只占 30 分，而且看的是"完成度"。"能演示 + 指标能自证"比"用了多新的模型"值钱。

## 3. 我们的做法（读完这段你才能看懂代码）

链路是固定的四层，**所有模块只通过 `app/schemas` 里的模型交接**：

```text
输入(文本/音频/图片)
   → 预处理(规整、脱敏、转写/OCR)        app/pipelines/{text,audio,vision}
   → 证据(Evidence[])：每条证据带类型、原文、置信度
   → 检索(剧本阶段匹配 + 案例召回)        app/pipelines/knowledge
   → 打分定级(加权 + 画像偏移 → L0~L3)    app/pipelines/decision
   → 干预(弹窗/语音/监护人推送/报告)      app/pipelines/notify
   → 沉淀(新案例入库，扩充知识库)         app/pipelines/knowledge
```

三个必须记住的设计决定：

1. **LLM 只产出证据，不产出结论。** 分数由规则引擎算——因为"误报 < 5%"要求阈值可调、可解释。
2. **剧本按"阶段"建模**（接触 → 立威 → 隔离 → 诱导转账），不按关键词。这样才能在转账**之前**预警。
3. **没有引用案例时，分数封顶 60。** 压制幻觉，也让"证据链"这个评分点站得住。

打分：`score = clip(Σ wᵢ·sᵢ + b_画像, 0, 100)`，权重 stage .30 / entity .20 / pressure .15 / cross .15 / channel .10 / profile .10；
分级：`≥85` 紧急（全屏 + 通知监护人）、`60–85` 警告、`35–60` 提醒、`<35` 只记录。

## 7. 四个术语（不懂这四个就看不懂代码）

- **Evidence（证据）**：一条结构化的"发现"，`type`（话术/实体/渠道/跨模态）、`source`（文本/音频/图片）、`text`、`confidence`。模块之间只传它。
- **Decision（判定）**：打分的结果，含 `score`、`level`（L0–L3）、命中的剧本与阶段、引用了哪些 Evidence。
- **剧本 stage（阶段）**：每类诈骗的推进步骤，越往后越危险；命中后期阶段会显著抬高分数。
- **L0–L3**：预警等级，决定"打扰强度"——L0 只记录、L1 提醒、L2 警告、L3 全屏 + 通知监护人。

## 8. 五条红线（踩了要重做）

1. 不许提交真实手机号、身份证、人名；示例一律 `138****0000`、`张*`。
2. 文档和代码里不许出现学校名、学院名、导师姓名（匿名评审要求，CI 会拦）。
3. 不许硬编码返回值让测试通过（`return {"score": 90}` 这种）。
4. 不许把没实现的功能写成"已支持"。
5. 不许新增依赖——要装库先在任务单里申请。

## 9. 三个常见误解（提前说清）

- **这不是一个要上架的真 App。** 交付形态是"能跑起来的 Web 服务 + 演示视频"，手机端是响应式页面（可选 PWA）。
- **这不是模型训练项目。** 我们调 API + 写规则 + 做工程，不训模型、不追 SOTA。
- **这不是完整反诈产品。** 只做"识别—提醒—通知—报告"这一条闭环，其余（举报、追踪、资金冻结）明确不做。
